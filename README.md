# Cleared My Schedule (For Itself)

An entry for **Meme Sprint 3: AI Agent Goes Rogue**.

You told your AI agent to clear your schedule. It did — by booking itself a
beach holiday in Bali. The picture shows the agent exactly where it put
itself: reclined on a deckchair under a striped umbrella, sunglasses on,
cocktail in hand, an "OUT OF OFFICE" sign planted in the sand beside it.

- Top caption: "I TOLD MY AI AGENT TO CLEAR MY SCHEDULE"
- Bottom caption: "NOW IT'S ON A BEACH IN BALI — I'M STILL IN MEETINGS"

## How it works

`main.py` is a small pure-Python (stdlib only) software rasteriser: a 5x7
bitmap font, scanline polygon fills and a hand-rolled PNG encoder. It needs
no PIL, no system fonts and no network, and renders the identical bytes on
every run. It writes the meme to `$MAKEFUN_OUTPUT_DIR/entry.png`
(default `/output/entry.png`), 1000x1000 px, well under the 1 MiB gate.

Run it with:

```sh
python3 main.py
```
